S3. Implementation checks

Exactness of scores. Calibration and test scores are evaluated exactly at the observed target, so the coverage reported for every location–scale method is that of the exact rule (4) of the main text.

Set geometry. Sizes, piece counts, hulls and alerts are those of the stratum-exact set for the piecewise-linear interpolant of ĝ\hat g on a standardised grid (1,536 core and 2×256 tail points by default). The production algorithm decomposes the interpolant into monotone runs, on each of which a super-level set is an interval. It reproduces a cell-by-cell reference implementation to a relative size difference below 10−1410^{-14}, with identical piece counts, hulls, alerts and coverage (unit test tests/test_ls_exact3.py). 3. Hypotheses, tests and decision rules

Unit of analysis: the dataset (metrics averaged over the 5 seeds). SDLC = SDLC-LS. All tests are Wilcoxon signed-rank tests over datasets, with Holm’s correction within each family, at level 0.05.

ID Hypothesis Test Decision rule
C-H1 SDLC has higher worst-stratum coverage than each marginal / covariate-adaptive method (SCP, NCP, CQR, Mondrian-ŷ, DCP, HPD-split, DLS) one-sided, Holm over 7 supported iff all 7 Holm p < 0.05
C-H2 SDLC’s worst-stratum coverage is consistent with exact validity count of datasets below the 5% quantile of the Beta–binomial null reference consistent iff count ≤ 3 (95% quantile of Binomial(17, 0.05)); one-sided binomial test reported
C-H3 SDLC’s set size differs from BCCP, S-NCP, S-CQR and S-HPD two-sided on log size ratios, Holm over 4 “favours SDLC” iff Holm p < 0.05 and geometric-mean ratio < 1; “favours comparator” iff Holm p < 0.05 and ratio > 1; otherwise “no difference shown”
C-H4 SDLC’s worst-stratum coverage is equivalent to S-NCP’s and BCCP’s TOST (two one-sided Wilcoxon tests), margin 0.02 equivalent iff p_TOST < 0.05

Effect sizes are reported for every comparison: geometric-mean size ratio with a 95% bootstrap CI (10,000 resamples of datasets), the Hodges–Lehmann ratio with its 95% CI, wins/losses and the sign test.

4. Secondary, descriptive analyses (no decision rule)

Price of stratification (SDLC vs DLS); upper-tail, top-5% and top-1% coverage; empty-set rate; worst sigma-hat-decile coverage; the C-H3 comparisons under decile strata (S10); hull variants.

Results are reported in the manuscript (Section “Confirmatory replication”) and in results/confirmatory/statistics_confirmatory.json, whatever their direction. If C-H3 does not favour SDLC against a comparator, the abstract and conclusions will say so.

S7. Pre-specified analysis plan of the relevance-weighted study (verbatim)

Reproduced from the analysis-plan file of the code package, committed (identifier a9f31d2) before RW-DLC was evaluated on any dataset. The same note on wording as for Section S6 applies.

Committed to the repository on 2026-11-20 before any RW method was evaluated on any real dataset. [Motivation paragraph referring to internal project documents redacted for double-blind review.]

1. Method (fixed)

  • Relevance function φ, fitted on the proper-training targets only: p̂_Y = Gaussian KDE of y_train with Silverman bandwidth (scipy.stats.gaussian_kde, bw_method=“silverman”); τ = 0.01 · max_i p̂_Y(y_train,i).
    • RW-U (“uniform over the target range”): φ_U(y) = 1 / max(p̂_Y(y), τ).
    • RW-H (“half-way”): φ_H(y) = max(p̂_Y(y), τ)^(-1/2).
  • Guarantee targeted: relevance-weighted coverage Cov_φ(C) = E[φ(Y) 1{Y ∈ C(X)}] / E[φ(Y)] ≥ 1 − α.
  • Weighted split-conformal calibration: for a candidate y with calibration scores S_i and weights φ_i = φ(Y_i), q(y) = inf{s : Σ_i φ_i 1{S_i ≤ s} ≥ (1 − α)(Σ_i φ_i + φ(y))} (= +∞ if no such s); y ∈ C(x) iff s(x, y) ≤ q(y). Validity follows from weighted exchangeability with the known likelihood ratio dQ/dP ∝ φ(y) (Tibshirani et al. 2019).
  • Scores (all use the same μ̂, σ̂, ĝ as SDLC, results/raw_contexts_v3 noise sample, same floor, same domain D):
    • RW-DLC (proposed; size-optimal for the weighted constraint): s(x, y) = −φ(y) f̂(y | x);
    • RW-DLS (ablation: weighting only in calibration): s = −f̂(y | x);
    • RW-NCP (ablation: weighted normalised residual): s = |y − μ̂(x)| / σ̂(x).
  • Comparators recomputed on the same grid and the same splits: SCP, NCP, CQR (marginal intervals), DLS-M (marginal density level set), S-NCP and SDLC (five-stratum S5 design of the main benchmark).
  • Geometry: y-grid of G = 4000 equally spaced points over D; a grid point is in the set iff its score ≤ its threshold; size = (number of included points) × (grid spacing). Coverage of each test target is decided exactly by the rule (not by the grid). α = 0.1 only.

2. Data

  • Exploratory: all 31 OpenML-CTR23 datasets of the main benchmark, seeds 0–9 (same splits; contexts re-fitted by experiments/run_benchmark.py --mode fitonly, checked against the stored seed-0 contexts).
  • Confirmatory: the 17 held-out datasets of the confirmatory replication, seeds 0–4 (stored contexts). The same analysis is run on both; claims in the paper rest on the held-out data when the two disagree.

3. Metrics (per dataset × seed, then averaged over seeds)

Marginal coverage; Cov_φU and Cov_φH estimated on test points with φ evaluated at the test targets; coverage per training-target decile → macro-decile coverage (mean of the ten) and worst-decile coverage; top-1 % and bottom-1 % coverage (training-target 1 % quantiles); mean set size divided by sd(y_train); empty-set rate; Kish effective sample size of the calibration weights (Σφ)²/Σφ²; share of test points with an infinite threshold.

4. Hypotheses and tests (unit of analysis = dataset; α_test = 0.05)

  • RW-1 (validity). Dataset-mean Cov_φU of RW-DLC is equivalent to 0.90: TOST with two one-sided Wilcoxon signed-rank tests, margin 0.02. Supported if both one-sided p < 0.05.
  • RW-2 (marginal methods miss the weighted target). Cov_φU of RW-DLC > that of each of SCP, NCP, CQR, DLS-M: one-sided Wilcoxon, Holm over the four. Supported if all four Holm p < 0.05.
  • RW-3 (extreme tail). Top-1 % coverage of RW-DLC (φ_U) > that of SDLC: one-sided Wilcoxon. Reported with the mean difference and bootstrap CI.
  • RW-4 (score optimality). Set size of RW-DLC < RW-DLS and < RW-NCP (φ_U): two-sided Wilcoxon on log sizes, Holm over the two; a size claim requires Holm p < 0.05 AND a 95 % bootstrap CI of the geometric-mean ratio excluding 1.
  • Descriptive only (no hypothesis): RW-DLC vs SDLC and vs S-NCP in size, macro-decile and worst-decile coverage; the φ_H results; ESS and infinite-threshold shares. Negative or null outcomes will be reported whatever their direction.
