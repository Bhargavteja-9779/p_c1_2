# REPRODUCIBILITY_STATUS

* **One command:** `python code/run_all.py --mode full` regenerates every result, table, figure, the manuscript,
  highlights, cover letter and supplementary material; `--mode quick` runs the unit tests and the complete v3 pipeline
  on 3 development datasets (verified 2026-11-18).
* **Data:** public OpenML datasets downloaded programmatically (CTR23 suite 353; confirmatory: suites 335/336), cached
  under `data/` with licence metadata (`data/<id>.json`, Supplementary Tables S1–S2).
* **Seeds:** main benchmark 0–9, confirmatory 0–4, synthetic 0–9 — all fixed in configuration before results were seen;
  split, model, subsampling and Monte Carlo seeds are derived deterministically.
* **Determinism:** fits are single-threaded; a re-fit check of cached scale models agrees to ~5e-8 relative; the fast
  set geometry reproduces the reference implementation to < 1e-14 (unit test).
* **Environment:** `code/requirements.txt` / `code/environment.yml` (exact versions; Python 3.13, CPU only).
* **Raw results in the repository:** `results/raw_eval_v3/` (per dataset × seed), `results/confirmatory/raw_eval_v3/`,
  `results/raw_mlp_v3/`, `results/raw_denseweight/`, `results/raw_grouped/`, `results/synthetic_v3.jsonl`,
  `results/tail_alerts.jsonl`, `results/raw_results_v3.csv.gz` (all runs in one table). Cached model outputs
  (`results/raw_contexts*`, several GB) are regenerated by the fitting step.
* **Pre-registration:** `PREREGISTRATION_confirmatory.md` + `code/scripts/analyze_confirmatory.py`, commit ccba99b,
  pushed before any confirmatory evaluation; the script was not modified afterwards (`git diff ccba99b -- …` is empty).
* **Known limitations:** LightGBM results can differ in the last digits across CPU architectures/library versions;
  author placeholders in the manuscript must be completed by the authors.
